# 🏨 Hotel Management System

## 📌 Project Overview

The Hotel Management System is a web-based application developed using Python, FastAPI, Streamlit, and SQLite.

It is designed to manage hotel-related activities such as customers, rooms, bookings, payments, and services through a simple web interface.

## 🎯 Objectives

- Manage customer information
- Manage hotel rooms and room status
- Manage customer bookings
- Manage payment details
- Manage hotel services
- Provide a simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- FastAPI
- REST API
- Streamlit
- SQLite
- SQL
- Pydantic
- Requests
